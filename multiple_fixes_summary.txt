## 🔧 **Multiple Fixes Applied - Testing Required**

### ✅ **Three Critical Issues Fixed:**

#### 1. **Window-Relative Coordinates** 
- **Problem**: Bot was using absolute screen coordinates instead of window-relative
- **Solution**: Added `_convert_to_window_coordinates()` method 
- **Effect**: Clicks now calculate proper position relative to game window

#### 2. **Unfocused Window Clicking**
- **Problem**: Clicks only worked when window was focused
- **Solution**: Added PostMessage-based clicking with window handle support
- **Effect**: Bot can now click on unfocused/background windows

#### 3. **Config Loading Override** 
- **Problem**: Loading config changed Mouse actions to Controller actions
- **Solution**: Bot now auto-detects action type regardless of stored input_mode
- **Effect**: `click` actions stay as Mouse actions even after config load
