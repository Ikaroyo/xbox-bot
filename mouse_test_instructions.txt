### Mouse Click Test Instructions

To test and debug mouse clicks in KB2JOY:

1. **Run the application**: `python app.py`

2. **Go to KB2JOY tab**

3. **Enable Debug Mode**: 
   - Look for "Debug Mode" checkbox and enable it
   - This will show detailed logs about mouse clicks

4. **Add a mouse mapping**:
   - Click "Add New Mapping" 
   - Set Xbox Button: "A" (or any button)
   - Set Input: "mouse_left" (for left mouse button)
   - Click "Add Mapping"

5. **Enable KB2JOY**:
   - Check "Enable KB2JOY" 
   - Check "Suppress Input" (optional)

6. **Test mouse clicking**:
   - Click anywhere with left mouse button
   - Check the logs for debug messages like:
     - "🖱️ Mouse click handler called..."
     - "🖱️ Converted mouse button: mouse_left"
     - "🎯 Mouse mapping found: mouse_left -> A"
     - "🎮 Pressing controller button..."

7. **Check for issues**:
   - If no logs appear: Mouse listener not working
   - If logs appear but no controller input: Virtual controller issue
   - If "Invalid controller button" error: Button name mismatch

### Expected behavior:
- Left mouse click should trigger Xbox A button
- Original mouse click should still work (not suppressed)
- Debug logs should show the conversion process
